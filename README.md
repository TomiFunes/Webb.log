# 📝 Webb.log

**Webb.log** is a lightweight personal blogging app built with Node.js, Express, and Bootstrap. It allows you to write, save, edit, and delete blog entries stored as local `.txt` files—no database required.

---

## 🚀 Features

- ✍️ Text editor using `<textarea>`
- 💾 Save blog entries as local files
- 📂 View all saved files
- 🔁 Edit existing entries
- 🗑️ Delete individual files
- 📅 Show creation date per file
- 🔢 Real-time word counter

---

## ⚙️ Technologies Used

- Node.js
- Express
- Bootstrap 5
- EJS (Embedded JavaScript templates)
- Vanilla JavaScript
- Node.js File System (fs)
